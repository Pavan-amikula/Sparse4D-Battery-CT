What these results do and do not mean
Simulation has a TIFF reference, so voxel RMSE can be calculated. Measured and enhancement modes have no ground truth, so no accuracy percentage is shown. Fit projection error is calculated on reconstruction views, not reserved views. A five-second processing target does not prove real-time scanner operation.
